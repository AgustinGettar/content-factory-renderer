# Video Generation Readiness V2

`VIDEO_GENERATION_READINESS_GATE_V2` is a deterministic fail-closed boundary before both the persistent video claim and any Higgsfield request.

## Required contract

1. `CANONICAL_START_STATE`: Lumi, props, educational objects, exact counts, geometry, visibility, and relevant positions.
2. `EDUCATIONAL_INVARIANTS`: one named invariant for every educational object.
3. `CHARACTER_INVARIANTS`: canonical face/silhouette; exactly two arms, legs, wings, and antennae; no tail, extra abdomen/appendages, or clothing mutation.
4. `ALLOWED_MOTION`: a closed list with at most one primary character action; secondary motion is limited to blink, subtle head movement, and subtle wings.
5. `FORBIDDEN_TRANSFORMATIONS`: duplication, disappearance, fusion, morphing, added shapes/limbs, body transformation, and geometry change are all forbidden.
6. `CAMERA_CONTRACT`: one continuous shot, `multi_shots=false`, static camera or one subtle push-in.
7. `END_STATE_CONTRACT`: Lumi and every educational object must remain visible, intact, and equal in count, geometry, and position.
8. `NATURAL_REAL_TIME_PACING_CONTRACT`: natural real-time motion, normal conversational gesture speed, natural blink/head/hand timing, no slow motion, no dreamy movement, and no prolonged pose holds. The only exception is an explicit pedagogical response window kept visually alive by allowed micro-motion.

The implementation is pure and deterministic in `lib/video-generation-readiness-v2.js`. A failed gate returns `provider_call_allowed=false` and `failure_cost_usd=0`.

## HIGGSFIELD_PROMPT_COMPILER_V2

The compiler accepts only a validated structured contract. It emits exactly these blocks:

1. `A_START_FRAME_AUTHORITY`
2. `B_CHARACTER_LOCK`
3. `C_EDUCATIONAL_OBJECT_LOCK`
4. `D_ALLOWED_ACTION`
5. `E_SECONDARY_MICRO_MOTION`
6. `F_FORBIDDEN_CHANGES`
7. `G_CAMERA`
8. `H_END_STATE`

There is no free-form scene action in the video provider prompt. Action, micro-motion, camera, and end-frame modes come from closed token sets.

`E_SECONDARY_MICRO_MOTION` also compiles the pacing contract. Every current six-scene repair prompt now explicitly requests natural real-time motion and forbids slow-motion or dreamy pacing. `s27` alone declares the exact 2.5-second pedagogical response window; it uses a static camera and one natural blink.

## VIDEO_SOURCE_READINESS_V1

Visual beauty or ordinary Visual QA acceptance is not sufficient. The persisted source assessment must prove:

- all required elements are present;
- exact counts and object set match;
- geometry is clear and non-ambiguous;
- props do not overlap ambiguously;
- Lumi anatomy is clean;
- pedagogical objects are fully visible;
- there is sufficient spacing for permitted motion;
- no visual ambiguity or extraneous educational object exists;
- confidence meets the scene threshold.

Missing evidence is a failure. The gate never infers readiness from `PASS` alone.

## Scene risk classifier

- `LOW`: no pedagogical identity/count/geometry lock.
- `PEDAGOGICAL_LOCKED`: counting, shapes, letters, numbers, or object identity. Stability takes priority over motion complexity.
- `HIGH_COMPLEXITY`: deterministic complexity flags such as several distinct examples or multi-object identity mapping. It requires static camera, spatial separation, no educational-object motion, and one character action maximum.

For `PEDAGOGICAL_LOCKED`, total generative motion load (primary action + secondary motions + camera moves) cannot exceed two. For `HIGH_COMPLEXITY`, camera is static and all mitigations are mandatory.

## Last-frame and CFG policies

`END_FRAME_MODE` supports `NONE`, `SAME_STATE_LOCK`, and `EXPLICIT_END_FRAME`. `last_image_url` remains globally disabled. No end frames are generated by this change.

`CFG_SCALE_TUNING_REQUIRED=true`. The current `cfg_scale=0.5` is unchanged. A later provider-authorized benchmark should use one or two representative scenes and measure prompt adherence, natural motion, and identity stability.

## Editorial gate before master

`EDITORIAL_MASTER_READINESS_GATE_V1` is separate from the provider gate and executes after caption/overlay layout and before master creation. It enforces:

- `TEXT_OVER_LUMI=FORBIDDEN` through a dynamic `CHARACTER_TEXT_EXCLUSION_ZONE` based on Lumi and critical-object bounding boxes;
- zero text overlap with Lumi and zero overlap with a critical educational object;
- suppression of technical pause labels such as `PAUSA`, `pause`, `wait`, and `hold` from captions and overlays;
- caption safe-area and readability checks;
- `PERCEIVED_PLAYBACK_SPEED=NATURAL_1X` with no clip stretching to fill a duration target;
- a content-driven 43–47 second target range, while preserving the exact 2.5-second response pause;
- measurements for static holds, unnecessary silence, transition duration, motion pacing, and perceived speed.

If no readable region remains, optional text is suppressed and required text fails layout. Covering Lumi is never a fallback. The current second short remains fail-closed at this gate because no final edit or frame-level bounding-box evidence exists yet.
